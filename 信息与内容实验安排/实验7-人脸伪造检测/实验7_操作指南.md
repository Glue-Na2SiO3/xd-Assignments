# 实验7: 人脸伪造检测 操作指南

## 一、实验目的

1. 掌握深度学习框架PyTorch的基本使用方法。
2. 学习使用预训练模型（ResNet）进行迁移学习，解决二分类问题。
3. 理解人脸伪造检测的基本原理和技术流程。
4. 掌握数据增强、模型训练、评估和可视化的完整实验流程。
5. 在真实与伪造人脸数据集上达到95%以上的分类准确率。

## 六、常见问题

### Q1: 提示 `CUDA out of memory`
**解决**: 减小batch_size：
```bash
python exp7_face_forgery_detection.py --batch_size 16
```

### Q2: 准确率一直很低（<60%）
**解决**: 
- 检查数据集路径是否正确
- 确认 real/ 和 fake/ 目录下图像数量正确
- 尝试使用 `resnet50` 代替 `resnet18`
- 增加训练轮数至50以上

### Q3: 没有GPU，训练很慢
**解决**: 代码已自动适配CPU运行。为加快速度，可以：
- 减少训练轮数用于测试
- 使用更小的模型（resnet18）
- 在Google Colab等免费GPU环境运行

### Q4: 百度网盘下载速度慢
**解决**: 
- 使用百度网盘客户端下载
- 或寻求其他下载方式（如同学分享）
- 模拟数据模式可先行验证代码正确性

### Q6: 如何加载训练好的模型进行预测？
**回答**: 使用以下代码片段：
```python
import torch
from torchvision import transforms
from PIL import Image

model = build_model(cfg)
model.load_state_dict(torch.load("outputs/best_model.pth"))
model.eval()

transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
])

img = Image.open("test.jpg").convert("RGB")
input_tensor = transform(img).unsqueeze(0)
with torch.no_grad():
    output = model(input_tensor)
    pred = torch.argmax(output, 1).item()
print("Real" if pred == 0 else "Fake")
```
