# 实验5: TensorFlow进阶 - Generative 操作指南

## 一、实验目的

1. 理解生成式深度学习模型的基本原理和应用场景
2. 掌握对抗样本生成方法（FGSM）及其实现
3. 学习DeepDream图像生成技术的原理与实现
4. 了解CycleGAN在图像风格迁移中的应用
5. 体验Stable Diffusion文本到图像生成技术
6. 培养使用TensorFlow实现生成式AI模型的能力

## 六、常见问题

### Q1: GPU内存不足
**现象**: OOM (Out of Memory) 错误
**解决**:
```python
# 在代码中添加
import tensorflow as tf
gpus = tf.config.list_physical_devices('GPU')
for gpu in gpus:
    tf.config.experimental.set_memory_growth(gpu, True)
```

### Q2: TensorFlow Hub模型下载失败
**现象**: 连接超时或SSL错误
**解决**: 设置代理或手动下载模型
```bash
set HTTP_PROXY=http://your-proxy:port
set HTTPS_PROXY=http://your-proxy:port
```

### Q3: Stable Diffusion生成失败
**现象**: 内存不足或模型加载失败
**解决**: 减小图像尺寸到256x256，或减少num_steps到15
```python
model = keras_cv.models.StableDiffusion(img_width=256, img_height=256)
images = model.text_to_image(prompt, num_steps=15)
```

### Q4: 中文显示乱码
**现象**: matplotlib中文标题显示为方块
**解决**:
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
plt.rcParams['axes.unicode_minus'] = False
```

### Q5: 运行速度过慢
**现象**: 每个步骤需要数分钟
**解决**: 确认GPU是否被使用，检查CUDA和cuDNN版本匹配
```bash
python -c "import tensorflow as tf; print('GPU:', tf.test.is_gpu_available())"
```
