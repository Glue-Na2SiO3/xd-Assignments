# 实验4: TensorFlow进阶 - Vision 操作指南

## 一、实验目的

1. 掌握使用TensorFlow进行计算机视觉任务的基本方法
2. 学习构建CNN模型进行图像分类（CIFAR-10数据集）
3. 理解迁移学习的原理，掌握使用预训练模型（MobileNetV2）进行特征提取和微调
4. 掌握数据增强技术及其在模型训练中的应用
5. 学习U-Net架构进行图像分割任务
6. 了解目标检测的基本方法，使用预训练模型进行推理
7. 熟悉GPU加速在视觉任务中的应用

## 六、常见问题

### Q1: TensorFlow Hub模型下载失败
**原因**: 网络连接问题或模型URL不可访问
**解决**: 
```bash
# 设置代理
export HTTP_PROXY=http://your-proxy:port
export HTTPS_PROXY=http://your-proxy:port
# 或手动下载模型文件
```

### Q2: tensorflow_datasets加载Oxford-IIIT Pet失败
**原因**: 数据集下载需要外网访问
**解决**: 
```bash
# 设置数据集缓存目录
export TFDS_DATA_DIR=/path/to/datasets
# 或手动下载并放置到~/.tensorflow_datasets/
```

### Q3: GPU内存不足 (OOM) - 视觉任务常见
**原因**: 图像尺寸较大或batch_size过大
**解决**: 
1. 减小batch_size（代码中已使用较小值）
2. 减小输入图像尺寸
3. 使用混合精度训练：`tf.keras.mixed_precision.set_global_policy('mixed_float16')`

### Q4: 迁移学习时MobileNetV2下载慢
**原因**: 模型权重文件较大（约14MB），网络慢
**解决**: 耐心等待或更换网络环境，权重会自动缓存到`~/.keras/models/`

### Q5: 目标检测部分报错
**原因**: TensorFlow Hub模型版本不兼容
**解决**: 
```python
# 尝试使用其他检测模型
detector = hub.load("https://tfhub.dev/tensorflow/ssd_mobilenet_v2/fpnlite_320x320/1")
```

### Q6: CIFAR-10下载失败
**原因**: 网络问题
**解决**: 
