# 实验1: PyTorch基础 操作指南

## 一、实验目的

1. 掌握PyTorch中Tensor的创建、属性和基本运算操作。
2. 理解PyTorch DataLoader的工作机制，能够加载和预处理图像数据集。
3. 理解Autograd自动微分原理，能够计算复杂函数的梯度。
4. 掌握使用`nn.Module`构建神经网络的方法。
5. 完成一个完整的图像分类任务（FashionMNIST），理解训练流程。

## 二、环境准备

### 2.1 系统要求
- Python >= 3.8
- CUDA >= 11.0 (如需GPU加速)

## 六、常见问题

### Q1: CUDA不可用怎么办？
**A**: 代码会自动回退到CPU运行。如需GPU加速，请检查：
1. NVIDIA驱动是否正确安装
2. CUDA版本与PyTorch是否匹配
3. `torch.cuda.is_available()`返回False的原因

### Q2: 下载FashionMNIST数据集很慢或失败？
**A**: 
1. 可以手动下载数据集放到`./data`目录
2. 使用国内镜像源
3. 检查网络连接

### Q3: 训练准确率很低？
**A**: 
1. 增加训练轮数(`num_epochs`)
2. 调整学习率
3. 尝试更复杂的网络结构
4. 使用数据增强

### Q4: 内存不足(OOM)？
**A**: 
1. 减小`batch_size`
2. 使用更小的网络
3. 使用混合精度训练

### Q5: 中文显示乱码？
**A**: 在代码开头添加：
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']  # Windows
plt.rcParams['axes.unicode_minus'] = False
```
