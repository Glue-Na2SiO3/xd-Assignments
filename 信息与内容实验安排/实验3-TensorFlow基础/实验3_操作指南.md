# 实验3: TensorFlow基础 操作指南

## 一、实验目的

1. 掌握TensorFlow的基本使用方法，包括环境配置、数据加载、模型构建与训练
2. 理解Keras Sequential API和Functional API的区别与使用场景
3. 掌握自定义训练循环的编写方法
4. 学习基本的机器学习任务：图像分类、文本分类、回归预测
5. 理解过拟合现象及正则化技术（L2正则化、Dropout）
6. 熟悉GPU加速配置和训练过程可视化

## 二、环境准备

### 2.1 激活conda环境

```bash
conda activate tf_env
```

> ```bash
> conda create -n tf_env python=3.10
> conda activate tf_env
> ```

```bash
pip install tensorflow numpy matplotlib pandas python-docx
```

## 六、常见问题

### Q1: 运行时报错 "Could not load dynamic library 'cudart64_110.dll'"
**原因**: CUDA版本与TensorFlow不匹配
**解决**: 
```bash
# 检查CUDA版本
nvidia-smi
# 安装对应版本的TensorFlow
pip install tensorflow==2.x.x  # 匹配CUDA版本
```

### Q2: GPU内存不足 (OOM)
**原因**: 显存被其他程序占用或模型过大
**解决**: 代码中已启用内存动态增长，如仍不足可减小batch_size

### Q3: Auto MPG数据集下载失败
**原因**: 网络连接问题
**解决**: 手动下载数据集并放置到正确位置，或检查网络代理设置

### Q4: 中文显示乱码
**原因**: Matplotlib默认字体不支持中文
**解决**: 
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']  # 或 'Microsoft YaHei'
plt.rcParams['axes.unicode_minus'] = False
```

### Q5: 训练速度过慢
**原因**: 未正确使用GPU或数据管道未优化
**解决**: 
1. 确认GPU被检测到
2. 使用tf.data进行数据预取和缓存
3. 使用@tf.function装饰器加速训练循环
