# 实验2: PyTorch进阶 操作指南

## 一、实验目的

1. 掌握使用TorchVision进行目标检测的方法，理解Faster R-CNN模型结构。
2. 掌握使用TorchText进行文本分类的方法，理解文本预处理流程。
3. 学习预训练模型的加载与微调(Fine-tuning)技术。
4. 理解不同领域(图像检测、文本分类)的深度学习应用差异。

## 二、环境准备

### 2.1 系统要求
- Python >= 3.8
- CUDA >= 11.0 (如需GPU加速)

### 2.2 创建并激活Conda环境

```bash
# 创建新环境
conda create -n pytorch_exp python=3.10 -y

# 激活环境
conda activate pytorch_exp
```

### 2.3 安装依赖

```bash
# 安装PyTorch (带CUDA支持)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 或者仅CPU版本
# pip install torch torchvision torchaudio

# 安装torchtext
pip install torchtext

# 安装其他依赖
pip install matplotlib numpy pillow
```

### 2.4 验证安装

```bash
python -c "import torch; import torchvision; import torchtext; print('PyTorch:', torch.__version__); print('TorchVision:', torchvision.__version__); print('TorchText:', torchtext.__version__)"
```

## 六、常见问题

### Q1: torchtext安装失败或版本不兼容？
**A**: 
1. 确保PyTorch与torchtext版本匹配
2. 尝试: `pip install torchtext==0.15.0` (根据PyTorch版本调整)
3. 使用conda安装: `conda install -c pytorch torchtext`

### Q2: Faster R-CNN模型下载很慢？
**A**: 
1. 模型权重文件较大(~160MB)，请耐心等待
2. 可以手动下载权重文件放到缓存目录
3. 使用国内镜像加速

### Q3: AG_NEWS数据集下载失败？
**A**: 
1. 检查网络连接
2. 手动下载数据集并放置到正确位置
3. 使用代理或VPN

### Q4: 文本分类训练速度很慢？
**A**: 
1. 确保使用GPU (`device = cuda`)
2. 减小词表大小或嵌入维度
3. 减小batch_size以节省内存

### Q5: 目标检测没有检测到任何目标？
**A**: 
1. 测试图像是合成图像，检测结果取决于预训练模型
2. 尝试使用真实照片进行测试
3. 降低置信度阈值(`score_threshold`)
