# 实验8: 学术前沿调研 操作指南

## 一、实验目的

1. 了解信息与内容安全领域的最新学术前沿和技术进展。
2. 培养独立调研学术论文、理解前沿技术的能力。
3. 学习制作高质量学术汇报PPT，提升学术表达能力。
4. 掌握学术报告的撰写规范，包括文献综述、技术分析和总结展望。

## 三、调研流程说明

```
阶段1: 选题（1-2天）
  └─> 阅读research_guide.md中的5个推荐方向
  └─> 在Google Scholar上初步检索相关论文
  └─> 确定最终调研方向

阶段2: 文献阅读（3-5天）
  └─> 精读2-3篇核心论文（尤其是近3年的顶会论文）
  └─> 泛读5-10篇相关论文建立知识框架
  └─> 记录每篇论文的创新点、方法、实验结果

阶段3: PPT制作（2-3天）
  └─> 按照8个部分规划PPT结构
  └─> 收集高质量图片、绘制架构图
  └─> 排版设计，确保无完整句子

阶段4: 报告撰写（1-2天）
  └─> 按照报告模板撰写调研报告
  └─> 补充截图、表格、参考文献

阶段5: 汇报准备（1天）
  └─> 准备讲稿，控制10-15分钟
  └─> 预演并调整PPT
```

```
"federated learning" "poisoning attack" AISTATS
"vision transformer" image classification ICCV

```

**预期输出**: 收集10-15篇相关论文的标题、作者、会议、年份。

### 步骤3: 精读核心论文

**操作**: 选择2-3篇最具代表性的论文进行精读。

**阅读重点**：
- Abstract & Introduction：理解问题定义和动机
- Related Work：了解技术发展历程
- Method：理解模型架构和算法细节
- Experiments：关注数据集、评价指标、对比结果
- Conclusion：总结创新点和局限

**预期输出**: 完成论文阅读笔记，记录创新点和技术细节。

## 六、常见问题

### Q1: 如何找到高质量的论文？
**解决**: 
- 优先选择CCF-A/B类会议论文（CVPR、ICCV、NeurIPS、ICML、AAAI、IJCAI等）
- 使用Papers With Code查看有开源代码的论文
- 关注高被引论文和近3年的最新工作

### Q2: 技术原理看不懂怎么办？
**解决**: 
- 先阅读该领域的综述（Survey）论文建立知识框架
- 查阅相关基础知识（如注意力机制、残差连接等）
- 参考知乎、CSDN、B站上的技术解读
- 不必追求理解每一个细节，抓住核心思想即可

### Q3: PPT中如何做到"无完整句子"？
**解决**: 
- 使用关键词短语代替句子，如用"ResNet50 backbone + Attention module"代替"We use ResNet50 as the backbone network and add an attention module"
- 用图表说话，将文字信息转化为流程图、架构图、对比表
- 使用 bullet points，每条不超过5个词

### Q4: 如何绘制漂亮的模型架构图？
**解决**: 
- 使用draw.io绘制，导出为高清PNG/SVG
- 参考原论文中的插图风格
- 使用统一的颜色编码（如蓝色=输入，绿色=特征，红色=输出）

### Q5: 参考文献格式要求？
**解决**: 
- 使用GB/T 7714标准格式
- 示例：[1] 作者. 标题[J]. 期刊名, 年份, 卷(期): 页码.
- 示例：[2] 作者. 标题[C]. 会议名, 年份: 页码.
- 建议使用Zotero或EndNote管理文献
