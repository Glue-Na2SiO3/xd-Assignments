# 实验6: 图像伪造实验 操作指南

## 一、实验目的

1. 理解图像风格迁移的原理和实现方法
2. 掌握使用TensorFlow Hub进行任意图像风格迁移
3. 了解生成式图像模型（BigGAN）的基本原理
4. 学习Boundless图像外推技术
5. 理解图像伪造的基本方法（复制粘贴、颜色篡改）
6. 掌握基本的图像伪造检测技术（误差分析、噪声分析）
7. 培养对图像真实性的鉴别能力

## 六、常见问题

### Q1: TensorFlow Hub模型下载失败
**现象**: 连接超时或SSL错误
**解决**: 设置代理或手动下载模型
```bash
set HTTP_PROXY=http://your-proxy:port
set HTTPS_PROXY=http://your-proxy:port
```

### Q2: BigGAN模型内存不足
**现象**: OOM错误
**解决**: 使用CPU运行或减小batch size
```python
# 在代码开头添加
import os
os.environ['CUDA_VISIBLE_DEVICES'] = '-1'
```

### Q3: scipy未安装
**现象**: ImportError: No module named 'scipy'
**解决**:
```bash
pip install scipy
```

### Q4: 风格迁移结果质量差
**现象**: 生成图像模糊或风格不明显
**解决**: 调整内容图像和风格图像的尺寸比例，确保风格图像具有明显纹理

### Q5: Boundless模型加载失败
**现象**: 404或模型不存在错误
**解决**: 检查模型URL是否正确，或使用替代方案（代码中已包含镜像填充的替代实现）
